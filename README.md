# Ecommerce-Sales-and-Profitability-analysis-Dashboard
Ecommerce Sales and Profitability analysis Dashboard using excel


Introduction:
"I built an E-commerce Sales and Profit Analysis Dashboard in Microsoft Excel using around 10,000 sales records from 2011 to 2014".

Business Problem:
"The business problem was that sales were growing year over year, but profits were not increasing at the same rate. Management wanted to understand the reasons behind this and identify opportunities to improve profitability".

Understanding Data:
"I started by first analyzing all the columns to understand what I was working with — fields like Sales, Profit, Discount, Category, Region, and Segment."

Data Cleaning:
"Then I cleaned the data — checking for nulls and duplicates, standardizing date formats,I also created a calculated Profit Margin column using the formula Profit ÷ Sales × 100, which helped compare profitability across products and regions".

Key Metrics:
"The key metrics I tracked were Sales, Profit, Profit Margin, Discount, and Order Volume."

Charts:
"The key chart in the dashboard is the profitability breakdown by Sub-Category — it showed Profit for each product type and exposed which ones were actually losing money despite decent sales."

Result:
"This revealed that Tables and Bookcases were losing money due to discounts above 30%, while Technology and the West/East regions performed best."

Recommedation:
"Based on these insights, I recommended reducing excessive discounts on loss-making products and focusing more on high-profit categories and regions. These recommendations can help improve overall profitability."
